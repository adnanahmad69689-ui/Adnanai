# Adnan AI Project Addition Plan

## Purpose

This plan adds three project formats without changing the portfolio’s dark editorial design: private website builds, public 3D websites, and AI workflows or agents. Each format uses the same premium card rhythm—one strong visual, concise facts, and one honest action—so the portfolio remains focused rather than becoming a mixed gallery.

## 1. Project Formats and Required Inputs

| Format | Required from you | Main visual | Safe label | Action button |
|---|---|---|---|---|
| **Private website** | Project name, 1–3 screenshots, industry, your role, 2–3 real features | One cleaned desktop screenshot in the browser-style frame | `Private build — demo available on request` | `Request a private demo` (email) |
| **Public 3D website** | Project name, public URL, 1–2 screenshots or a short clip, your role, 2–3 interactive features | A strong hero/interactive screenshot | `Live website` | `Visit live site ↗` |
| **AI workflow or agent** | Workflow screenshot or diagram, trigger, task, input, output, tools used, whether a person approves results | Workflow canvas or simple flow diagram | `Private system` if it cannot be shared publicly | `Request system details` or `View workflow` |

## 2. Consistent Card Structure

Every project should use the same information order. This keeps the portfolio visually consistent while allowing the content to change by project type.

1. **Category label:** `PRIVATE BUILD`, `LIVE 3D SITE`, or `AI AGENT`.
2. **Project title:** A clear business or system name.
3. **One-sentence purpose:** What the website, workflow, or agent is meant to help with.
4. **Main visual:** One polished screenshot, video thumbnail, or workflow diagram.
5. **Three factual highlights:** Features you built, not unverified outcomes.
6. **Technology/service tags:** Only technologies or methods you are comfortable publishing.
7. **One honest action:** A live link only when it is public; otherwise an email request action.

> Do not use fictional results, client testimonials, made-up traffic numbers, or unsupported claims. A private build can still look professional when its visual evidence and feature list are clear.

## 3. Visual Rules That Preserve the Current Site

| Element | Rule |
|---|---|
| **Private screenshots** | Use one main image. Add a smaller second image only when it shows a genuinely different page, interaction, or footer/system view. |
| **Public 3D work** | Use a high-impact still image first. The external link is secondary so your portfolio remains visually strong even if the source site changes. |
| **AI workflows** | Use a cleaned workflow canvas, diagram, or interface—not a browser frame. Keep the workflow steps legible. |
| **Image preparation** | Remove browser chrome, desktop taskbars, private client data, email addresses, order details, and personal information. |
| **Copy length** | Keep the title short, purpose to one sentence, and each highlight to one line. |
| **CTA count** | Use one project action only. Multiple buttons make the card look less premium. |

## 4. Staged Addition Order

The portfolio should grow in small, curated batches.

| Stage | Add | Why |
|---|---|---|
| **Stage 1** | One private website, one public 3D website, and one AI workflow/agent | Establishes the three formats without overcrowding the site. |
| **Stage 2** | Add one detailed case study for the strongest project | Gives prospective clients a deeper example without forcing every card to become long. |
| **Stage 3** | Add 2–3 more projects only after screenshots and copy are approved | Maintains quality and visual rhythm. |
| **Stage 4** | Add an admin/database system only if you need to add, edit, hide, reorder, or publish projects yourself | Avoids building unnecessary infrastructure now. |

## 5. Database Decision

A database is **not needed now**. Static data is the best choice while you are choosing screenshots, refining copy, and adding a small curated set of projects. Add a database later only if you want a login-protected admin dashboard to manage projects without changing code.
